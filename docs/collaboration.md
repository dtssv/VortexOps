# 协作与体验

涵盖工作台、全局搜索、收藏、审批流、通知、动态流、评论、公告、回收站、配额、标签等提升功能完整性与使用体验的能力。所有协作与体验增强内容统一在此文档。

---

## 1. 工作台（Dashboard）

**目标**：登录后一屏掌握「与我相关」的全局状态。

### 1.1 卡片模块（可拖拽布局，存 `user_preferences.dashboard_layout`）

| 卡片 | 内容 | 权限 |
| --- | --- | --- |
| 待我审批 | 待审批发布/配置数量，一键跳转 | 有审批权限 |
| 进行中构建 | 当前用户/空间 running 构建，进度条 | `menu:build:view` |
| 进行中发布 | running 发布及进度 | `menu:release:view` |
| 最近失败 | 24h 内失败构建/发布 | 同上 |
| 我的收藏 | 收藏的空间/应用/分组 | 全部 |
| 最近访问 | 最近 10 条资源 | 全部 |
| 空间概览 | 各空间应用数、健康分组数 | 有空间权限 |
| 系统公告 | 置顶公告滚动 | 全部 |
| 构建趋势 | 7 日构建成功/失败折线图 | `menu:build:view` |
| 发布日历 | 近 7 日发布时间线 | `menu:release:view` |

### 1.2 体验细节

- 空状态引导：新用户展示「创建空间 → 创建应用 → 首次构建」步骤条。
- 卡片支持隐藏/排序，布局云端同步。
- 关键数字点击直达详情（如「3 个待审批」→ 审批列表）。

## 2. 全局搜索（Command Palette）

**快捷键**：`Ctrl+K` / `Cmd+K`

搜索范围：
- 空间、应用、分组（名称/标签）
- 构建号、发布号
- 镜像 Tag
- 菜单项（无权限的不出现）

结果分组展示，Enter 跳转；支持拼音首字母（可选）。

## 3. 收藏与最近访问

### 3.1 收藏（`user_favorites`）

- 空间列表、应用卡片、分组详情页均可「星标收藏」。
- 侧边栏顶部「我的收藏」折叠组，快速跳转。
- 支持拖拽排序。

### 3.2 最近访问（`user_preferences.recent_resources`）

- 自动记录最近访问的 20 条资源。
- 工作台展示；下拉切换空间/应用时优先展示最近项。

## 4. 审批流

### 4.1 配置

- 按空间/应用/分组配置审批流（`vo_approval_flows`）。
- 触发条件：`release.rolling` + `environment=prod` 等；中间件变更 `middleware.upgrade` / `middleware.scale` + `environment=prod` 同样支持。
- 多级审批：应用 Owner → 空间 Admin → 指定用户。
- 超时自动拒绝或提醒（可配置）。

### 4.2 体验

- 工作台「待我审批」卡片。
- 站内信 + 邮件/钉钉/飞书（`vo_notification_deliveries`）。
- 审批页展示：变更摘要、镜像/配置 diff、一键通过/拒绝 + 评论。

### 4.3 与权限的联动

- 审批动作 `action:approval:approve` / `action:approval:reject` 由审批流步骤指定审批人（角色/用户/应用 Owner），**不**完全依赖应用角色。
- 生产分组可设 `release_requires_approval=true`，发布进入 `pending_approval`，审批通过后自动执行。
- 详见 [权限体系](permissions.md#审批权限)。

## 5. 通知系统

### 5.1 通知类型

| 类型 | 触发 |
| --- | --- |
| 构建 | 成功/失败/取消 |
| 发布 | 成功/失败/待审批/审批结果 |
| 中间件 | 安装/升级/扩缩容/备份成功失败/恢复完成 |
| 审批 | 待审批、超时 |
| 系统 | 公告、集群不可用 |
| @mention | 评论中被 @ |

### 5.2 渠道

- 站内（必选）
- 邮件（可选）
- Webhook / 钉钉 / 飞书（空间级配置）

### 5.3 用户偏好（`user_preferences.notification_settings`）

```json
{
  "build_failed": {"in_app": true, "email": true},
  "release_prod": {"in_app": true, "email": true, "dingtalk": true},
  "approval_pending": {"in_app": true, "email": true}
}
```

## 6. 回收站

- 软删除资源进入 `recycle_bin`，保留 30 天（可配置）。
- 菜单：`回收站`（需 `action:recycle:view`）。
- 支持按类型筛选、恢复、彻底删除（purge，需 admin）。
- 恢复时校验名称冲突。

## 7. 配额与限制

`vo_workspace_quotas` 控制：
- 最大应用数、分组数、并发构建数、镜像保留数、成员数。
- 接近上限时 UI 黄色警告；达到上限阻止创建并提示联系 admin。

## 8. 标签与筛选

- 空间/应用/分组/镜像支持 `labels`（key/value）。
- 列表页标签筛选器；标签管理弹窗。
- 与 K8s labels 可选同步（分组创建时写入 Deployment）。

## 9. 动态流与评论

### 9.1 动态流（`vo_activity_feeds`）

- 空间/应用级动态流：谁构建、谁发布、谁改配置。
- 便于团队感知变更，减少沟通成本。

### 9.2 评论（`comments`）

- 构建/发布详情页「评论」Tab，支持 @mention 触发通知。
- 发布单协作讨论。

## 10. 系统公告

- 平台/空间级公告（`announcements`）。
- 顶栏滚动条展示 critical 公告；工作台卡片展示普通公告。
- 支持定时发布与过期。

## 11. 审计增强

- 操作 diff 可视化（before/after 字段级对比）。
- 按操作人、资源、动作、时间筛选；导出 CSV。
- 敏感操作高亮标记：凭证查看、生产发布、purge、**中间件密码查看、中间件生产升级、备份恢复覆盖、PVC 数据删除**。

## 12. 运维观测增强

| 能力 | 说明 |
| --- | --- |
| Pod 日志 | 终端风格、搜索、下载、多 Pod 切换 |
| 跨 Pod 日志搜索 | 按关键词/正则在分组所有 Pod 日志中检索，高亮、导出、跳转实时流 |
| Pod 终端 | exec 进入容器调试，生产需权限+审计（可选录屏） |
| 端口转发 | 临时转发平台端口到 Pod，调试内部服务无需暴露 |
| 事件中心 | 跨分组 K8s Event 聚合 |
| 资源监控 | 集成 Prometheus（CPU/内存曲线，可选） |
| 健康状态 | 分组概览红/黄/绿：副本就绪、探针、最近发布 |
| 集群概览 | 节点数、Namespace 数、平台管理 Deployment 数 |
| 中间件监控 | 实例健康、副本就绪、备份状态、连接数（可选集成 exporter 指标） |
| 中间件拓扑 | 应用↔中间件依赖图，影响面分析（中间件故障/升级反查受影响应用） |
| 告警中心 | 规则化告警（发布失败/重启过多/CPU 高/中间件宕机/备份失败/HPA 到顶），多通道通知，静默，事件追踪 |
| 弹性伸缩观测 | HPA 实时副本数、伸缩事件、到顶告警 |

### 12.1 告警中心

- **规则**：内置常见规则（发布失败、Pod 重启过多、Pod Pending、构建失败率、中间件宕机、备份失败、HPA 到顶），支持自定义 Prometheus PromQL 与 K8s Event 规则。
- **通知联动**：告警触发即按规则配置的通道推送（站内/邮件/IM/Webhook），并写入 `vo_alert_events`。
- **静默**：维护期或已知问题可静默特定规则/范围，到期自动恢复。
- **事件追踪**：firing → resolved 全生命周期，可手动解决、评论、关联工单。
- **与通知区别**：通知是事件被动推送（如「构建成功」），告警是规则主动评估（如「连续 3 次构建失败」）。

### 12.2 CI/CD 流水线可观测

- **流水线看板**：跨空间流水线 run 概览，成功率、活跃流水线、最近失败。
- **MTTR/MTBF**：统计从失败到恢复的平均时长、平均间隔，衡量交付稳定性。
- **DORA 指标**：部署频率、变更前置时间、变更失败率、恢复时长。
- **瓶颈分析**：各阶段耗时分布，定位慢阶段（如测试占 60% 耗时）。
- **失败聚类**：按失败原因/阶段聚类，常见问题一目了然。
- **流水线事件纳入审计与活动流**：触发、门禁通过/拒绝、晋升审批等均审计。

### 12.3 大模型推理监控

- **推理指标**：吞吐（tokens/s、requests/s）、延迟（TTFT、P50/P95/P99）、队列长度、KV cache 占用。
- **GPU 指标**：每卡显存利用率、计算利用率、温度（DCGM Exporter）。
- **用量监控**：Token 消耗趋势、按 API Key/调用方分布、配额逼近告警。
- **告警规则（内置）**：
  - 推理服务不可用（Pod 全不就绪）
  - 错误率突升（5xx > 阈值）
  - 延迟 P99 突增
  - 显存接近上限（>95%，防 OOM）
  - HPA 到顶仍过载
  - 权重下载/校验失败
  - 切模型失败自动回滚
- **审计**：推理服务变更（部署/切模型/扩缩容/回滚/停止）、API Key 签发撤销、模型版本管理均审计，切模型属敏感操作高亮。

## 13. 国际化与主题

- i18next：中/英切换（`users.locale`）。
- 深色/浅色/跟随系统（`user_preferences.theme`）。

## 14. 体验细节清单

| 场景 | 体验设计 |
| --- | --- |
| 长任务 | 构建/发布提交后 toast + 后台进行，可离开页面；完成推送通知 |
| 表单 | 分步向导 + 步骤间校验 + 上一步数据保留 |
| 列表 | 列自定义、排序、筛选条件 URL 同步（可分享） |
| 错误 | 统一错误码 + 人类可读文案 + traceId 复制 |
| 加载 | Skeleton 骨架屏；长列表虚拟滚动 |
| 确认 | 危险操作 Modal 输入资源名确认 |
| 快捷键 | Ctrl+K 搜索、Esc 关闭抽屉 |
| 复制 | 镜像地址、Commit SHA、构建号一键复制 |
| 空状态 | 插画 + 引导按钮 + 文档链接 |
| 新手引导 | 首次登录分步导览，按角色聚焦入口 |
| 权限 | 无权限菜单不显示；按钮不渲染 |
| 离线 | 构建/发布日志 WS 断线自动重连 + 补拉历史 |
| 移动端 | 非优先；审批、查看状态类页面基础适配 |
| 帮助 | 复杂字段「?」悬浮说明 + 跳转使用文档 |
| 日志排障 | 阶段化分块、全文搜索高亮、错误行自动定位、日志对比、下载分享（见 [构建与发布 §4.4.1](build-release.md#441-日志查看体验增强)） |
| 进度反馈 | 发布/构建进度条 + 阶段耗时 + 预估剩余时间；卡住时提示原因 |
| 失败恢复 | 失败一键「用相同参数重试」；灰度失败自动回滚并提示；配置/制品可回退任意版本 |
| 资源预估 | 创建分组/推理服务时实时预估 CPU/内存/GPU/显存占用与配额余量，超限前置提示 |
| 模板复用 | 资源模板/构建模板/发布预设/流水线模板，减少重复配置 |
| 自助服务 | 用户自助建空间（无需管理员），策略控制配额与上限 |
| 对外集成 | API Token + scope + 范围 + IP 白名单 + 回调，外部系统安全接入 |
| 操作即文档 | 关键操作可生成对应 API/curl 示例，便于研发复用 |
| 批量操作 | 批量发布/扩缩容/加成员，减少重复点击 |
